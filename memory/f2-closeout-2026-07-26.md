# F2 closeout review

**Date:** 2026-07-26  
**Task:** F2  
**Status:** Review ready with named external blockers

## Proven

- The linked development installation has exactly the four approved read
  scopes: `read_orders`, `read_all_orders`, `read_payment_terms`, and
  `read_customers`.
- Basic-store company/contact, email-only protected-data, current, overdue,
  paid, refunded, cancelled, edited, zero-outstanding, multi-currency, and
  missing-email behavior were exercised with sanitized evidence.
- Shopify API `2026-07` query costs were observed without retaining response
  payloads.
- A database-backed embedded preview persisted expiring offline-session
  metadata.
- Real `app/scopes_update` events were emitted during a reversible scope test.
  The original four-scope configuration and local synthetic session state were
  restored from Shopify's authoritative granted-scope query.

## Named external blockers

- Cloudflare returned `530` for real webhook delivery before the application
  handler received the request, including with a separately managed fixed-port
  quick tunnel. Public app and unsigned fail-closed route probes succeeded.
- Live offline-token rotation and concurrent refresh need a reliably reachable
  authenticated runtime.
- Plus-only partial-payment proof needs a Plus sandbox or development store.
- A safe supported workflow for an authoritative negative-outstanding Shopify
  fixture was not established.
- App Pricing runtime states need a Manage-apps Partner API client and a
  configured private test plan.
